How this log is built

This log compares recorded Get-AzPolicyAlias snapshots. It includes differences reconstructed from the snapshots retained in this repository and subsequent successful collections. Collection is scheduled daily at 06:00 UTC, with additional weekly and manual runs. Event dates are observation times, not Microsoft's publication or retirement dates.

Added means an alias appeared for a resource type in the later snapshot; Removed means it was absent after being observed. Aliases can disappear and reappear between scans. Scope, provider responses and collection behavior may affect these observations; a removal does not prove that Microsoft retired the alias.

Modified means the same resource type and exact alias name had a different recorded default path. Expand the event to compare Before and After. Casing and [*] remain unchanged. Renamed aliases or resource types are shown as removals and additions, not guessed renames. null means no path was supplied by the source and is distinct from an empty string.

The baseline is the oldest compared snapshot, not an official launch date. The first snapshot is not reported as additions. Up to 180 days and 3,000 events are retained at each refresh; this cap can exclude older events or part of a busy day. The retained log is not the complete history of Azure.

Each event records both observation timestamps, its provider, resource type, alias and observed path. Reconstructed events also retain the source commit IDs in the JSON export. API-version-specific paths, modifiability metadata and policy-rule behavior are not stored in the source dataset and are not inferred here.

Counts and exports include all matching retained events, not only the displayed batch. Search also checks resource types and before/after paths. Recent periods use UTC calendar days ending today. Inspect the source log or download the current alias snapshot.
