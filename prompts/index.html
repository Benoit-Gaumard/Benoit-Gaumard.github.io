💬Prompts

My library of ready-to-use AI prompts for Azure, infrastructure as code, DevOps and everyday productivity. Fill in the blanks, preview the result, then copy it or open it straight in your favorite assistant. Star the ones you like: favorites are remembered on this device.

      How to use these prompts

      Each prompt is a template. Words in {{double braces}} are blanks you fill in before sending it to an AI assistant.

      • ✍️ Fill in the blanksOpen a prompt to get one field per blank. The preview updates as you type, and anything still empty is highlighted.
      • 📋 Copy or openCopy the finished prompt, or send it straight to ChatGPT, Claude or Perplexity in a new tab.
      • 🧩 Use it in VS CodeDownload any prompt as a .prompt.md file for GitHub Copilot. Unfilled blanks become ${input:...} variables that Copilot asks for.
      • ⭐ Keep your favoritesStar a prompt to find it again with the Favorites filter. Favorites stay in your browser only.
      • 🔗 Share a promptEvery prompt has its own link, so you can send a colleague exactly the one you mean.
      • 🛡️ Mind your dataNever paste secrets, customer data or confidential code into a public AI service. Use your organization's approved assistant for anything sensitive.

      Where the prompts come from

      I write and test these prompts myself, mostly with GitHub Copilot, Microsoft 365 Copilot and ChatGPT. Each one is a Markdown file in the prompts/library folder on GitHub, and the library is rebuilt every time the site is deployed. Results always depend on the model, so review what the AI gives you before you use it.
