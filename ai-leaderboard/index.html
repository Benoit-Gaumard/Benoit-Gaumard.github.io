Sources and methodology

  • Reference: LMArena leaderboardThe official, live leaderboard run by LMArena (formerly Chatbot Arena, UC Berkeley). lmarena.ai/leaderboard
  • Data: LMArena leaderboard datasetWeekly snapshots published by LMArena on Hugging Face under the CC BY 4.0 license. huggingface.co/datasets/lmarena-ai/leaderboard-dataset
  • Enrichment: OpenRouter models APIRelease dates, context windows, modalities and list prices of models served through OpenRouter. openrouter.ai/models
  • Scores come from LMArena's Bradley-Terry model with style control, which discounts answer length and markdown formatting. The ± value is half the 95% confidence interval.
  • The trend column compares the overall text rank with the previous Arena snapshot stored by this page.
  • Prices, context windows and release dates are matched to Arena models by name and only shown when a confident match exists; check the provider for official pricing.
  • A GitHub Actions workflow refreshes this page every Monday. You can also download the dataset (JSON).
